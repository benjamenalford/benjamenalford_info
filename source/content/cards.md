# Cards

How many shuffles until a deck of cards reaches a starting point?
## Standard Bridge Order
- A->K->J->Q->10->...
- Spade -> Heart -> Diamonds -> Clubs

## Initial Setup
The deck has been arranaged as described above. A 'traveler' card has been added to the deck as the top most card. If one were to flip the cards it would be as such: Traveler <T> -> 1 <2S> -> <3S> -> <nSuit>
